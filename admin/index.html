새 작품

MP4 파일 업로드

작품 정보를 입력하고 MP4를 선택한 뒤 파일 업로드를 누르세요. 새 작품은 비공개로 먼저 저장되고, 전송이 끝나면 영상 URL이 자동 입력됩니다.

MP4 영상을 여기에 끌어다 놓으세요 파일 1개 · 최대 500MB

선택된 파일 없음

완료되면 영상 URL이 입력됩니다. 아래 ‘저장’을 눌러 작품에 반영하세요. MP4를 HLS로 변환하지 않습니다. 업로드한 파일은 저장하지 않거나 URL을 교체해도 Storage에 남습니다. 공개 후 영상 URL을 가진 사람은 재생할 수 있습니다.

비공개 전환은 새 목록 조회에 반영됩니다. 이미 제공한 영상 URL의 접근 권한을 회수하는 기능은 아닙니다.
