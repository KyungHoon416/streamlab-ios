새 작품

MP4 파일 업로드

작품 정보를 입력하고 MP4를 선택한 뒤 파일 업로드를 누르세요. 새 작품은 비공개로 먼저 저장되고, 전송이 끝나면 영상 URL이 자동 입력됩니다.

MP4 영상을 여기에 끌어다 놓으세요 MP4 파일 1개

선택된 파일 없음

큰 영상의 압축 계획

2GB 이상 파일입니다. 용량과 화질 중 우선할 기준을 선택하세요. 실제 압축은 Mac에서 진행합니다.

압축 방식

최대 1080p · HEVC MP4. 원본 비율을 유지하고 작은 영상은 확대하지 않습니다.

Mac에서 같은 원본의 앞·중간·뒤 장면을 합쳐 60초 정도의 샘플을 만드세요. 최대 1080p, 위 프레임 설정, HEVC CRF 28, AAC 96kbps를 사용합니다.

큰 파일은 전송이 끝날 때까지 이 페이지를 열어 두세요. 원본 파일을 업로드하며 자동 압축하지 않습니다. 비공개 작품에는 업로드한 URL이 자동 저장됩니다. 공개 상태 변경은 아래 ‘저장’을 눌러 작품에 반영하세요. MP4를 HLS로 변환하지 않습니다. 업로드한 파일은 저장하지 않거나 URL을 교체해도 Storage에 남습니다. 연결된 영상은 웹에서 로그인 없이 재생할 수 있습니다.

체크하면 iOS 앱에도 표시됩니다. 웹에서는 앱 비공개 작품도 누구나 보고 재생할 수 있습니다.
