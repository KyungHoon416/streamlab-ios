# 홈 이어보기의 다운로드 우선 재생

2026-11-01

## 문제와 변경

다운로드한 Apple HLS와 스트리밍 HLS는 같은 progress ID를 사용한다. HomeRecentModel의 첫 소스 매핑은 스트리밍이므로 저장 파일을 재생한 기록도 홈 이어보기에서 다시 원격 URL을 선택했다. 다운로드 목록에서는 로컬 재생이 가능해도 홈에서는 네트워크 재생을 시도하는 연결 누락이었다.

실제 UI 검증에서 별도 문제도 재현됐다. 홈 카드에는 HLS 기록이 있지만 cover가 기본 번들 데모로 열렸다. 작품과 소스를 각각 @State로 전달하던 구조를 HomePlaybackPresentation 하나로 묶어 cover의 item이 title/source를 함께 소유하도록 변경했다. 기본 ExtractedHomeView와 비교용 InlineHomeView 둘 다 적용했다.

ContinueWatchingSection의 카드 탭 시점에 동일 계정·프로필·작품의 유효한 다운로드가 있으면 downloadedHLS로 전달한다. 다른 HLS 소스/번들 소스는 변경하지 않는다. 파일이 없거나 만료/미완료/재생 불가능이면 기존 스트리밍 선택을 유지한다.

OfflineDownloadStore의 기존 acquire 검사와 소스 선택 검사를 하나의 내부 함수로 공유한다. 세션 활성 여부, 활성 계정, 로그아웃 차단, 완료 상태, 만료, 컨테이너 내부 파일, AVAssetCache의 offline playable 상태를 검사한다. 선택 조회는 LRU 갱신/lease 생성 없이 수행하고 실제 재생 준비에서 다시 acquire해 기존 lease·삭제 보호·권한 검사 경계를 유지한다. 선택 이후 삭제/만료되면 로컬 파일 오류를 표시하며 몰래 원격 재생으로 바꾸지 않는다.

## 검증

전용 스크립트: `bash scripts/check-offline-continue-mac.sh`.

- 실제 Apple HLS 다운로드 완료 → 저장 파일 재생으로 진도 기록 → 홈 이어보기 → 다운로드 소스 표시·복원·하단 시간 진행.
- 같은 파일을 만료시킨 후 홈 이어보기에서 만료 파일 대신 기존 HLS 스트리밍 선택.
- 기존 번들 영상의 홈 이어보기·진도 복원 회귀.

최종 실행 `offline-continue-aEoxGn`: UI 2개, 실패 0개 PASS. Xcode 빌드 warnings-as-errors 및 스크립트 구문·diff 공백 검사 PASS. 외부 HLS 접속이 필요하며 physical airplane mode와 동일한 시험은 아니다.

앞선 실행은 숨기지 않는다. `offline-continue-LP8JBI`는 초기 로그인 화면에서 실패하여 신규 기능에 도달하지 못했다(원인 미확정). `offline-continue-vtDqah`는 HLS 카드가 번들 데모로 열리는 소스 전달 오류를 재현했다. 후자의 앱 코드를 수정한 뒤 최종 실행에서 다운로드·만료·번들 경로를 모두 통과했다. 기본 PV 홈을 UI 검증했으며 비교용 Inline 홈은 동일 구조 수정 및 빌드 확인 범위다.

## 실기기 확인 완료 — 사용자 보고

2026-11-01, 사용자가 최신 코드의 실기기 비행기 모드에서 홈 이어보기를 선택했을 때 다운로드 영상·하단 시간·탐색이 정상 동작한다고 보고했다. 이 경로는 실기기 확인 완료로 기록한다. 별도 원시 로그나 영상은 첨부되지 않았으며 앱 재실행 후 같은 경로는 이번 보고에 명시되지 않았다. F09 만료/갱신 불가 및 F10 자막/단절 조합의 완료로 확대하지 않는다.

## 재현 순서

1. 기존 권한 만료 등 Debug 시험 인수를 끄고 최신 앱 설치.
2. 같은 프로필에서 HLS 샘플 다운로드 완료 → 다운로드 목록에서 10초 이상 재생하고 닫기.
3. 비행기 모드로 바꾸고 Wi-Fi도 끄기 → 홈의 ‘계속 시청’ 카드 선택.
4. ‘다운로드한 HLS 샘플’ 표시, 저장된 위치 복원, 영상/하단 시간/탐색 진행 확인.
5. 닫기·재실행 후 같은 홈 카드에서도 확인. 완료 후 네트워크 복구.

저장 파일이 없거나 만료됐다면 오프라인 재생은 제공할 수 없다. 기존 다운로드 만료/재다운로드 정책은 유지한다. 운영 콘텐츠나 DRM 서버를 새로 추가한 구현은 아니다.
