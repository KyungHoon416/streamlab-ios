HLS Leaks 분할 측정 분석

part1~part4 모두 xctrace TOC/Leaks 내보내기 성공(exit 0).
모든 파일의 누수 결과 행 0개. 각 Run 아카이브에 XRLeakSnapshotInfo 기록 존재 확인.
누수 검사에서 검출된 객체 없음. 스냅샷별 성공/실패 수와 UI 마커 수는 이번 분석에서 집계하지 않음.

파일은 누적 저장본: part1 1 Run, part2 2 Runs, part3 3 Runs, part4 4 Runs.
시작 시각과 누수 아카이브 SHA-256으로 중복을 확인하여 각 Run을 한 번만 집계.
part1 새 구간: 327.439초, 누수 행 0
part2 새 구간: 343.593초, 누수 행 0
part3 새 구간: 343.815초, 누수 행 0
part4 새 구간: 332.761초, 누수 행 0
총 고유 기록 시간: 1347.608초
사용자 확인 기준 5회 x 4구간 = HLS 20회. 실제 HLS 진입 횟수를 trace에서 독립적으로 세지는 않음.
이는 분할 누수 검사 결과이며, 동일 프로세스 연속 20회 메모리 증가율 검증과 다름.
part5 및 이전 시험 파일은 집계에서 제외. 원본 수정/코드 변경/깃 푸시 없음.
