# F05 플레이어 알림 관찰자 수명 검증

2026-11-01

## 추가 범위

- 오디오 interruption begin/end 및 route 변경 관찰자를 10회 생성/해제한다. 살아 있을 때 알림별 정확히 1회 콜백, 해제 후 콜백 없음, callback capture 해제를 검사한다. outputVolume KVO의 초기 알림은 중복 인터럽트로 세지 않으며 관찰자 해제 후 capture가 남지 않는지도 확인한다.
- 영상 종료/실패·미디어 서비스 리셋 관찰자를 10회 생성/해제한다. 다른 아이템 알림 무시, 현재 아이템의 각 콜백 정확히 1회, 해제 후 무응답·capture 해제를 검사한다.
- 실제 번들 AVPlayer 재생/닫기 10회마다 닫힌 상태에 오디오·리셋·옛 아이템 알림 6종을 게시한다. MainActor 후속 작업 뒤 idle/player nil/Now Playing nil 유지와 다음 재생 정상 시작을 확인한다.

## 결과

- 기존 22개 + 신규 3개 = iOS 패키지 25개 PASS, 30.430초. 필수 17개 성공 표식 모두 확인.
- 실제 재생/닫기 10회 및 늦은 알림 시험 PASS(7.250초). 관찰자별 10회 생성/해제·객체 필터·콜백 capture 해제 PASS.
- 최초 테스트 빌드에서 Xcode 27의 변경하지 않는 weak 지역 변수 경고가 오류로 처리됐다. 기존과 같은 weak reference 래퍼로 수정해 경고 억제 없이 재실행했다.
- 앱 관찰자 정리 결함은 발견되지 않아 런타임 변경 없이 테스트와 CI gate만 보강했다.
- 원격 CI 확인 예정.

## 한계

앱이 직접 소유한 세 종류 관찰자와 닫힌 모델의 동작을 확인한다. OS 전체 observer 수를 조회한 것, 실제 미디어 서비스 재시작, 블루투스 연결 해제, 시스템 메모리 압박 또는 AVPlayer 내부 객체가 즉시 해제됨을 증명하는 검사는 아니다. 기존 Instruments 메모리/Leaks 보고와 별개다. 음량을 실제로 변경하지 않는다. 이 검증만으로 F05 실기기 모든 조건을 완료 처리하지 않는다.

재현: `bash scripts/check-playback-session-lifecycle-mac.sh`. 추가 실기기 trace는 필요 없다.
