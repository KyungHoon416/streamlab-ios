# F04 탐색 중 닫기와 프로필 전환 UI 검증

2026-11-01

## 범위

기존 패키지 테스트는 seek 중 세션 무효화와 B 플레이어/Now Playing 격리를 직접 확인한다. 새 UI 테스트는 실제 사용자가 가능한 경로인 A 재생 → 탐색 바 중간 이동 → 탐색 완료 대기 중 닫기 → 홈 → 프로필 B → 새 영상 재생을 연결한다.

기존 Debug 인수 `--ui-test-stall-seek-once`로 A의 첫 seek 완료 처리를 보류한다. 닫기 직전에 재생 버튼 비활성 상태를 검사해 탐색 대기 중임을 확인한다. B에 이어보기 표시가 없고 시간이 진행하며, A의 8초 watchdog 시간 이후에도 B 재생과 닫기가 정상인지 검사한다.

이 주입은 늦은 AVFoundation 콜백 자체를 새로 전달하는 시험이 아니다. 패키지의 세대/세션 경계 검증과 UI 전환 검증을 분리한다. 플레이어 위에서 직접 프로필을 전환하는 UI는 없으므로 존재하지 않는 경로를 추가하지 않는다. 실제 HLS/네트워크 지연/실기기 전체 F04 완료로 확대하지 않는다.

## 재현

`scripts/check-profile-boundaries-mac.sh`는 기존 4개와 신규 1개의 총 5개 테스트를 요구한다. 전체 앱 UI suite와 구분한다.

실기기에서는 기존 만료 시험 인수를 끄고 정상 데모 재생 → 탐색 바 이동 후 닫기 → 프로필 변경 → 새 영상의 시간 진행과 닫기를 확인하면 된다. 탐색 대기 race는 자동 주입으로 확인하므로 손으로 정확한 타이밍을 맞추거나 trace를 만들 필요는 없다.
