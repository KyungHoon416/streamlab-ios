# HLS 네트워크 복구 수동 검증

현재 상태: NOT TESTED. 시뮬레이터에서 사용자 실행 후 결과를 기록한다.
자동 오류 주입 테스트 통과를 실제 네트워크 복구 통과로 대체하지 않는다.

## 준비
- 최신 앱을 일반 실행한다. UI 자동 테스트와 동시에 조작하지 않는다.
- 성인 A → 상세 → 데모 영상 재생 → 영상 소스 → HLS 스트리밍 선택.
- 오프라인 데모는 네트워크 검증에 사용하지 않는다.
- 선택한 소스, 프로필, 기기/OS, 중단 직전 재생 시간을 기록한다.

## 1. 연결 중단과 복구
1. HLS 영상이 실제 재생되는 것을 확인한다.
2. Mac의 활성 네트워크 연결을 끊는다. Wi-Fi 외 유선 등 다른 경로가
   남아 있으면 오프라인 조건이 아니다. 시뮬레이터만 조작해서는 보장되지 않는다.
3. 이미 받은 영상은 계속 재생될 수 있다. 로딩/오류가 발생하는지 확인한다.
   영상이 끝날 때까지 중단되지 않으면 버퍼링 복구는 NOT TESTED로 남긴다.
   필요하면 연결이 끊긴 상태에서 아직 받지 않은 구간으로 이동해 본다.
4. 로딩 중 다시 연결했을 때 재생이 복구되는지 확인한다. 앱은 연속 로딩
   약 30초에 오류 처리하며, 시킹에는 별도 약 8초 제한이 있다.
5. 오류 상태라면 네트워크 복구 후 '재생 다시 시도'를 누른다.
6. 실제 영상/소리가 재개되고 로딩이 사라지는지 확인한다. 자막/음성 선택과
   재생 위치도 확인한다. 시간 표시만 움직이는 것으로 통과 판정하지 않는다.

## 2. 로딩 중 종료
1. 연결 중단으로 로딩이 발생한 상태에서 닫기를 누른다.
2. 상세 화면 복귀와 원래 방향 복원을 확인한다.
3. 연결을 복구해도 닫은 영상의 소리가 뒤에서 재생되지 않아야 한다.
4. 같은 영상을 다시 열어 정상적으로 재생 가능한지 확인한다.

## 3. 백그라운드
1. HLS 재생 중 시뮬레이터 홈으로 나간다.
2. 앱으로 돌아왔을 때 자동 재생되지 않고 일시정지 상태인지 확인한다.
3. 재생 버튼을 누른 후 영상/음성/자막이 정상 진행하는지 확인한다.
