# HLS 네트워크 상태 배너 검증

새 배너의 모든 실행 검증은 NOT TESTED에서 시작한다.

## 자동 회귀

```bash
cd ~/Desktop/streamlab-ios &&
git pull --ff-only --no-rebase origin main &&
caffeinate -i bash scripts/check-pip-mac.sh
```

기존 재생/일시정지/이어보기 회귀이며 네트워크를 실제로 끊는 테스트는 아니다.
RESULTS.txt와 실패 시 ui-tests.log를 보관한다.

## 수동 검증

1. HLS 재생 중 인터넷을 끊는다. 재생 중에는 배너가 숨겨지는지 확인한다.
   버퍼에 남은 영상은 계속 재생돼도 정상이다. 로딩/일시정지 중 경로가 없으면 중립색 안내, 실제 실패 시 빨간 안내가 나온다. 닫기와 컨트롤이 가려지면 FAIL.
2. 인터넷을 복구한다. 오류 상태라면 영상 실패 안내와 기존 재생 다시 시도를 확인한다.
   다시 시도 후 정상 재생되면 배너가 사라지는지 확인한다.
3. 먼저 일시정지한 뒤 연결 끊기/복구를 반복한다. 자동 재생되지 않아야 한다.
   복구 안내를 확인하고 직접 재생해 배너가 사라지는지 확인한다.
4. Wi-Fi 연결만 유지하고 실제 외부 접속이 안 되는 경우 영상 실패 안내가 나와야 한다.
   경로 상태만으로 영상 재생 성공을 표시하지 않는다.
5. 오프라인 데모로 전환하면 네트워크 배너가 없어야 한다.
6. 로딩 중 닫기 후 다른 프로필로 다시 열어 이전 복구 안내가 남지 않는지 확인한다.
7. 최대 글자 크기와 VoiceOver에서 배너를 읽을 수 있고 닫기/재시도에 접근 가능한지 확인한다.

시뮬레이터의 경로 상태는 Mac 네트워크 구성에 영향을 받는다. Wi-Fi SSID나
인터넷 성공 표시가 아니며 특정 서버 장애의 원인을 확정하는 진단도 아니다.
배너는 전체 화면 앱 UI다. 시스템 PiP 창 안에는 표시하지 않는다.
