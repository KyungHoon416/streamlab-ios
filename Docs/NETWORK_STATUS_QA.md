# 앱 공통 네트워크 배너 검증

## 현재 동작

프로필 선택, 홈, 검색, 상세, 전체 화면 플레이어에서 하나의
NetworkConnectionStatus를 공유한다. NWPathMonitor 콜백으로 경로 변화를 수신해
MainActor에서 즉시 반영한다. 연결 경로가 없으면 빨간 배너, 경로가 복구되면 숨김.
앱이 다시 활성화되면 새 monitor로 현재 상태를 재확인한다.
재생 중이거나 오프라인 데모여도 연결이 없으면 표시한다.
네트워크 배너는 AVPlayer의 play/pause/load를 호출하지 않는다.
전체 화면 cover는 공통 환경 객체를 상속하며 자체 safe-area inset으로 표시한다.
자막 선택 패널과 시스템 PiP 창 안에는 배너를 별도로 표시하지 않는다.

## 한계

이는 네트워크 경로 관찰이다. Wi-Fi가 연결된 채 공유기의 외부 인터넷만 끊기거나
영상 서버만 장애가 난 경우까지 판별하는 HTTP 접속 검사는 아니다.
이 경우 플레이어의 실제 요청 오류와 재생 다시 시도 안내를 사용한다.
시뮬레이터는 Mac의 네트워크 상태에 영향을 받으며 콜백 전달 시점은 OS가 결정한다.
연결 표시만으로 HLS 서버 접속 성공을 보장하지 않는다.

RESULTS.txt와 실패 시 ui-tests.log를 보관한다.

## 수동 검증 (이번 수정은 모두 NOT TESTED)

1. 홈에서 인터넷 연결 경로를 끊고 빨간 배너가 표시되는지 확인한다.
2. 검색과 상세로 이동해 같은 빨간 배너가 유지되는지 확인한다.
3. 프로필 선택으로 돌아갔다 다른 프로필에 들어가도 상태가 동일한지 확인한다.
4. 번들 영상 재생 중에도 배너가 유지되는지 확인한다. 재생을 막으면 FAIL.
5. 화면을 이동하지 않고 연결을 복구한다. 현재 화면에서 배너가 사라져야 한다.
6. 일시정지 상태에서 연결을 끊고 복구한다. 자동 재생되면 FAIL.
7. 앱을 백그라운드로 보낸 뒤 연결을 바꾸고 복귀해 상태가 갱신되는지 확인한다.
8. HLS 요청 자체가 실패하면 기존 오류와 다시 시도 버튼이 유지되는지 확인한다.
9. 최대 글자 크기 및 VoiceOver에서 배너를 읽고 닫기/뒤로가기/검색 버튼에 접근한다.

연결 끊기/복구를 각 화면에서 3회 반복하고 기기/OS와 함께 결과를 기록한다.
참고: https://developer.apple.com/documentation/network/nwpathmonitor
