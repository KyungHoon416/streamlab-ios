# 외부 영상 연결 오류 알림 QA

현재 정책은 기존 네트워크 배너 정책을 대체한다. 프로필 선택에만 연결 경로 없음 배너를 표시하고, 홈/검색/상세/플레이어 배너는
제거했다. 실제 외부 HLS 로딩이 실패하면 취소/재시도 알림을 표시한다.
연결 경로 힌트만으로 재생을 차단하지 않는다. 버퍼 재생은 계속될 수 있으며
오류 확정 또는 기존 로딩 제한(30초)까지 알림이 바로 뜨지 않을 수 있다.

- 취소: 플레이어 정리 및 닫기. 상세에서 시작했으면 해당 상세로 복귀.
  홈에서 시작했으면 cover 닫기 완료 후 해당 작품 상세로 이동.
- 재시도: 같은 프로필/작품/소스로 기존 load를 다시 호출.
- 재시도가 다시 실패하면 알림을 다시 표시.
- 번들 데모 오류는 기존 인라인 오류/다시 시도 UI 유지.
- HLS 실패 원인은 인터넷 단절로 단정하지 않고 서버 문제 가능성도 안내.

## Mac 검증 — 모두 NOT TESTED

```bash
cd ~/Desktop/streamlab-ios &&
git pull --ff-only --no-rebase origin main &&
caffeinate -i ./scripts/verify-mac.sh
```

1. 프로필 선택에서 연결 끊김 시 빨간 배너, 복구 시 해제를 확인. 홈/검색/상세/플레이어에는 배너가 없어야 한다.
   연결 없이 홈/검색/상세의 번들 카탈로그가 표시되는지 확인. 프로필 재진입 시 상태도 확인.
2. 상세에서 HLS를 열고 실제 네트워크 차단. 로딩 실패 후 알림 확인.
3. 취소를 눌러 원래 상세 복귀, 세로 방향 복원 및 숨은 소리 없는지 확인.
4. 홈의 HLS 이어보기에서 같은 실패를 유도하고 취소 시 해당 작품 상세 확인.
5. 인터넷 복구 후 재시도하면 동일 영상이 재생되고 알림이 닫히는지 확인.
6. 인터넷이 없는 상태로 재시도하면 실패 후 알림이 다시 뜨는지 확인.
7. 최대 글자/VoiceOver로 알림 및 두 버튼 접근 확인.

기존 전체 자동 회귀는 실제 네트워크 단절/새 알림 경로를 자동 검증하지 않는다.
