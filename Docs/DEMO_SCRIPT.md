# 제출용 5분 시연 대본

2026-11-05 기준. 실기기에서 확인한 F10과 F09를 같은 프로필로 두 구간에 나눠 촬영한다. 아래 시간은 편집 계획이며 제출 영상은 아직 녹화하지 않았다.

## 촬영 준비

- Scheme은 `StreamLab-Firebase`, Run은 `FirebaseDebug`를 사용한다. Xcode에서 실행하고 실제 촬영 커밋·기기·iOS를 기록한다.
- Wi-Fi에서 ‘Apple HLS 연결 확인용 샘플’을 미리 다운로드한다. ‘F10 영어 자막 HLS 샘플’은 검색으로 열어 스트리밍한다. 두 작품을 구분하면 버퍼 재생과 저장 파일 재생을 영상에서 구별할 수 있다.
- A 구간에는 `--firebase-catalog`만 켠다. B 구간에는 `--ui-test-entitlement-offline-expired`를 추가하고 Xcode에서 다시 실행한다. 메모리 측정과 다른 오류 주입은 끈다.

| 시간 | 화면에서 보여줄 동작 |
|---|---|
| 00:00–00:55 | 프로필 선택 → 홈 → F10 검색 → 작품 상세 → 나의 리스트 추가. 공개 카탈로그는 Firebase에서 가져오고 찜은 프로필별로 저장된다고 설명한다. |
| 00:55–01:40 | ‘영상 재생’ → 탐색 바를 중간으로 이동 → 하단 시간 진행 확인 → 영어 자막 선택. |
| 01:40–02:30 | 비행기 모드를 켜고 Wi-Fi 끄기 → 연결 끊김 배너 확인 → 플레이어 닫기 → 다운로드 탭에서 미리 저장한 다른 작품 재생. |
| 02:30–03:10 | 저장 영상 닫기 → Wi-Fi 재연결 → F10 작품을 새로 스트리밍. 영상과 하단 시간이 진행되는 10초를 연속으로 보여준다. |
| 03:10–03:25 | ‘F09 재현을 위해 만료 인수를 켜고 재실행했습니다’라는 전환 자막을 넣는다. |
| 03:25–04:30 | B 구간에서 비행기 모드와 Wi-Fi 끄기 확인 → 같은 프로필 다운로드 목록 → ‘Apple HLS 연결 확인용 샘플’ 재생 → 가운데 만료 안내 → 재시도 → 갱신 실패·남은 2회 → 닫기 → 목록의 파일 유지 확인. |
| 04:30–05:00 | 아키텍처와 검증 요약. Firebase 카탈로그, 기기 내 다운로드, Mock 재생 권한의 역할을 설명한다. |

## 녹화 후

최종 영상을 처음부터 재생해 F10 재연결 뒤 10초와 F09 갱신 실패·목록 복귀가 보이는지 확인한다. 개인 알림이나 계정 정보가 노출된 구간을 확인하고 촬영 후 만료 인수를 끈다. 최종 파일 경로와 실제 촬영 조건을 [제출 점검표](SUBMISSION_CHECKLIST.md)에 기록한다.
