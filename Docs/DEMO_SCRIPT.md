# 제출용 5분 시연 대본

2026-11-01. **대본 준비 완료 / 실제 녹화 미완료.** 정상 기능과 장애 2개(네트워크 단절, Mock 권한 만료)를 보여준다. 아래 시간은 계획이며 실제 촬영 시간이 검증됐다는 뜻은 아니다.

## 촬영 전 준비

- 제출할 Git 커밋, iPhone/iOS, 빌드 구성, 네트워크를 기록한다. 개인정보가 없는 데모 계정을 사용한다.
- A 구간은 Scheme `StreamLab`의 일반 실행으로 준비한다. 기존 `--ui-test-*` 장애 주입 인수를 모두 끈다. 과도한 글자/레이아웃 실험 인수도 끈다.
- 성인 프로필에서 Apple HLS 샘플 1개를 미리 다운로드하고 저장 파일 재생을 확인한다. 다운로드 대기 시간을 영상에서 숨겨 실시간 완료처럼 설명하지 않는다.
- 네트워크 단절을 보여줄 때 셀룰러와 Wi-Fi를 모두 끈다. 비행기 모드에서 Wi-Fi가 다시 켜져 있지 않은지 확인한다.
- B 구간은 별도로 Debug 빌드의 Run Arguments에 `--ui-test-entitlement-expires-during-playback-once`만 켜서 실행한다. 첫 grant 수락 약 10초 뒤 만료되며 재시도는 정상 Mock grant를 받는다.
- **두 구간을 이어 붙이는 구성**이다. A/B 전환에 ‘권한 만료 테스트 빌드로 재실행’ 자막을 넣는다. 한 세션 연속 촬영이나 성능 벤치마크처럼 제시하지 않는다. 인수 변경·빌드 대기 시간은 촬영 전 준비에 포함한다.

## 녹화 후 검사

- 영상 길이 약 5분, A/B 전환 표시, 장애 2개와 각각의 복구 결과가 보이는지 확인한다.
- 만료 안내만 보여주고 끝내지 않는다. 재시도 뒤 하단 시간이 실제로 증가하는 구간을 포함한다.
- 개인정보/토큰/개인 파일 경로가 영상에 노출되지 않도록 촬영 화면을 확인한다.
- 파일 이름 예: `streamlab-demo-5min-YYYYMMDD.mp4`. 파일 생성 후 [제출 점검표](SUBMISSION_CHECKLIST.md)에 실제 경로·촬영 커밋을 적는다.
- 촬영 후 만료 인수를 해제한다. 자동 테스트 PASS가 녹화 완료를 대신하지 않는다.
