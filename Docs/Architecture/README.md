## 재생성

Python ReportLab과 Pretendard Regular/Bold TTF가 필요하다. 기본 글꼴 위치는 macOS `~/Library/Fonts`이며 다른 위치는 환경 변수로 지정한다.

```sh
STREAMLAB_FONT_DIR=/path/to/pretendard python3 Docs/Architecture/build_integrated_pdf.py
```

생성 후 Poppler로 모든 페이지를 렌더링하고 시각 검수한다. 생성기는 본문 Markdown을 덮어쓰지 않는다. 내용 변경 시 PDF와 생성 기록의 해시·페이지·검증 범위도 함께 갱신한다.
