# ADR 0018 — 없는 언어와 재생 불가능한 트랙의 대체 처리

저장된 프로필 선호와 현재 영상의 유효 선택을 분리한다. 영상에 없는 언어로 인한
fallback은 선호를 덮어쓰지 않으며 이후 영상/재실행에서 다시 복원한다.

- 자막: 언어 일치 → 유효 기본 트랙 → 끄기(허용 시).
  끄기가 불가능하면 첫 재생 가능 트랙을 사용한다.
- 음성: 언어+역할(DVS/일반) 일치 → 같은 언어의 다른 역할 → 기본/첫 재생 가능 트랙.
- 목록의 isPlayable=false 항목은 선택 목록에서 제외하며 선택 직전에도 재확인.
- 선택 가능한 항목이 없으면 사용 불가를 안내한다. 필수 자막을 강제로 끄거나
  존재하지 않는 AVMediaSelectionOption을 nil 선택으로 처리하지 않는다.
- 목록 재요청 시 이전 그룹/선택 목록을 비워 오래된 항목을 표시하지 않는다.
- 사용자 명시 선택만 프로필 선호를 저장한다.

## 검증
Core TrackFallbackTests 4개: 없는 언어, 필수 자막, DVS 역할 대체, 빈 목록,
잘못된 기본 인덱스, 재정렬 후 선호 복원.
UI는 Debug 전용 --ui-test-missing-korean-episode에서 데모 2화만 한국어를 제외:
한국어 선택 → 2화 끄기 대체 → 3화 한국어 복원 → 재실행 유지 → B 프로필 끄기.
이는 동일 언어 resolver와 실제 선택 UI/저장 경로를 검증하나 native HLS 그룹
로딩/선택 자체의 장애를 재현하지 않는다. 실제 HLS missing/unplayable 트랙은 별도 검증 필요.
Production 영상 데이터는 변경하지 않는다.
