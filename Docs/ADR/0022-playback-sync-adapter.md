# ADR 0022 — A3 플레이어 Mock 어댑터

상태: 구현, Mac 검증 대기 (2026-10-16)

Debug 상세의 가상 기기 A/B 선택을 PlaybackModel 생성 인자로 전달한다.
모드가 없으면 기존 UserDefaults를 사용한다. Mock 선택 시 같은 프로필/작품/소스의
서버 값을 읽은 후 AVPlayer를 생성하고 유효한 위치만 실제 seek한다.
종료/주기 저장은 서버에 제출하며 기존 로컬 진도를 쓰거나 참조하지 않는다.

MainActor coordinator는 제출된 이벤트의 FIFO를 보장한다. 새 플레이어 open은
직전에 제출된 close 저장 완료를 기다린다. 각 플레이어는 독립 snapshot을 갖는다.
큐에 저장된 위치 값은 캡처된 이벤트이며 같은 세션의 연속 저장에만 revision을 순차 적용한다.
다른 세션과 충돌하면 해당 세션은 이후 쓰기를 중단한다. 충돌된 과거 이벤트를 최신revision으로
자동 재전송하지 않는다. 새 플레이어를 열어 명시적으로 서버 상태를 다시 읽는다.

restart는 기존 체크포인트 뒤에 순서대로 제출한다. 처리 중 플레이어를 일시정지하고
seek/일반 저장을 막는다. 서버가 수락한 경우에만 실제 seek(0)를 수행한다.
닫기나 프로필 변경 이후 완료는 generation/session 검사로 UI에 반영하지 않는다.
이미 제출한 쓰기는 기존 identity에만 적용되며 새 프로필에 기록되지 않는다.

Mock 서버는 앱 프로세스 범위의 메모리 actor다. 다른 시뮬레이터나 실기기와 통신하지 않고
앱 종료 시 초기화된다. 홈 계속 시청/회차 진도 레일은 기존 로컬 저장을 사용한다.
Debug 선택 패널에서만 접근하며 운영 동기화 서비스로 표시하지 않는다.

검증: Core 어댑터 3개, 실제 플레이어 UI 1개. Swift/Xcode 미설치이므로 NOT TESTED.
Core 기존 56개 및 독립 A3 8개는 사용자 로그로 PASS(중복 합산하지 않음).
