# ADR 0010 — 프로필별 재생 위치 저장

상태: 채택, Mac 검증 대기

MainActor PlaybackProgressStore는 프로필 ID를 생성 시 고정한다. 작품·소스 ID와 함께
독립 인코딩한 키로 UserDefaults에 Codable 레코드(position/duration)를 저장한다.
소스 버전은 동일 길이의 다른 영상으로 교체되는 경우에도 개발자가 갱신해야 한다.

저장 주기는 5초이며 닫기/백그라운드/소스 변경/세션 무효화 직전에도 실제 player 시간을 저장한다.
시킹 도중의 낙관적 목적지 값은 저장하지 않는다. 세션 무효화 후 쓰기를 금지한다.
기존 권한 검증 후 item 준비 및 finite duration 확인을 거쳐 위치를 복원한다.
복원이 실패하거나 중단되면 기존 저장 위치를 보존한다. 사용자가 다시 재생/이동하면 새 위치 저장을 허용한다.
시킹별 generation과 foreground generation을 재사용해 늦은 완료 및 백그라운드 후 자동 재생을 차단한다.

1초 미만 및 마지막 min(5초, duration*5%)는 기록을 삭제한다. 이전 길이와 1초/1% 중 큰 값 이상 차이나면 복원하지 않는다.
완료 여부는 별도 시청 완료 이력이 아니며 다음 재진입 시작점 정책이다.
앱 강제 종료 직전의 최대 약 5초 진행은 손실될 수 있고 OS 영속화 타이밍까지 보장하지 않는다.

Core 테스트: 재생 기록 재생성, 프로필/작품/소스 분리, 완료/0초 초기화, NaN/길이 변경.
UI 테스트: 15초 저장, 앱 재실행, 복원, 처음부터 보기와 재진입.
기존 테스트의 결정성을 위해 Debug에서만 저장/복원 비활성 및 별도 suite 주입을 제공한다.
