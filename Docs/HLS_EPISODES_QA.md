# 실제 HLS 회차 연결 검증

플레이어의 영상 소스 선택에서 **HLS 테스트 시즌 · 1화/2화**를 선택한다.
실제 작품의 회차가 아니라 기존 Apple 공개 스트리밍 샘플 두 개를 연결한 테스트 시즌이다.
1화: bipbop_4x3_variant.m3u8 테스트 패턴.
2화: adv_dv_atmos/main.m3u8 오디오 비교 샘플.
원본 파일을 다운로드/재배포하지 않는다. 외부 서버 가용성과 네트워크 연결이 필요하다.
상세 화면의 기존 로컬 데모 3회차 목록은 그대로이며, HLS 시즌은 플레이어 소스 메뉴에서 진입한다.

## 자동 검증
caffeinate -i bash scripts/check-hls-episodes-mac.sh

Core 실행 후 실 네트워크 HLS UI 테스트 두 개를 실행한다.
1화 끝으로 seek → ended → 10초 자동 카운트다운 → 2화 실재생 → 마지막 종료.
1화 일부 재생/seek → 2화는 새 진도 → 1화 복귀 시 저장 위치 복원 안내.
실패/skip은 PASS로 처리하지 않는다.
일반 전체 회귀에서는 외부 서버 의존 테스트를 skip하며 이는 NOT TESTED다.
전용 스크립트는 TEST_RUNNER_STREAMLAB_TEST_REAL_HLS=1로 실행을 활성화한다.

## 수동 확인
- 1화 20초까지 시청 후 닫기/재진입: 1화 위치 복원.
- 처음 보는 2화: 1화 진도를 사용하지 않는다.
- 1화 끝으로 이동: 10초 카운트다운 취소 후 자동 이동 없음.
- 다시 끝까지 재생 후 다음 화 지금 재생: 2화.
- 마지막 2화 종료: 자동 다음 화/무한 반복 없음.
- 다음 화 전환 중 인터넷 차단: 취소/재시도 알림. 취소 시 상세 복귀.
- B 프로필 첫 진입: A의 HLS 회차 진도 없음.

현재 자동 테스트는 seek로 종료 지점까지 이동한다. 전체 길이 자연 재생 완료, 장시간
네트워크 장애, 실기기, 영상 권한/라이선스 Mock은 별도 검증이다.
HLS native 자막/오디오 누락 시나리오의 통과 근거로 사용하지 않는다.
